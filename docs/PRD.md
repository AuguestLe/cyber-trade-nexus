## 1. 项目概述

### 1.1 背景与目标

搭建一个面向展厅 / 汇报 / 演示场景的**大屏数据可视化产品**，模拟全球金融交易实时态势。核心价值在于「观感 + 交互」：以赛博朋克 HUD 视觉呈现交易流水、资金流向与全球节点关系，并提供大量可点击、可筛选、可下钻的交互点，让演示者能现场操作讲解。

### 1.2 三个必须成立的产品特征

1. **赛博感**：暗色底、霓虹描边、扫描线、切角 HUD 卡片、发光数字、故障字效、粒子与飞线动效，整体像科幻指挥中枢而非后台报表。
2. **交互密度高**：目标 35+ 个明确交互点，覆盖悬停、点击下钻、筛选、时间回放、图层开关、速率控制、身份切换、快捷键等（详见第 9 节）。
3. **地图独立成页**：全球交易地图是独立页面，用地图库渲染世界底图 + 交易节点，并**根据交易双方（from / to）生成空中弧线连线**；首页大屏只保留一个简化版地图做概览，点击可跳转地图页。

### 1.3 范围边界

**包含**：登录页、角色权限、首页大屏、全球交易地图页、交易明细、管理员控制台、本地 Mock 数据生成器、视觉与动效体系、分辨率适配。

**不包含**：真实行情接入、真实下单 / 清算 / 撮合、真实用户体系与服务端鉴权、资金与账户数据、外部地图瓦片服务、移动端适配、多语言、数据导出到文件系统（截图导出可选）。所有数字均为模拟值，界面需有「DEMO / 模拟数据」标识，避免误解为真实交易系统。

### 2.3 实现方式（前端 Mock 鉴权）

- 本地用户表 + 角色表，`src/mock/api.ts` 暴露异步 `login / logout / getSession`，模拟 300~600ms 延迟。
- 会话存 `localStorage`（含角色、过期时间），刷新保持；退出即清除。
- `react-router` 路由守卫 `<RequireAuth roles={[...]}>`，未登录跳登录页，越权跳 403 视图。
- 组件级 `usePermission()` / `<Can permission="...">` 控制按钮显隐与禁用。
- 右上角身份徽章支持「一键切换演示身份」（管理员专属），便于现场演示权限差异。
- **安全声明**：前端 Mock 鉴权仅用于演示，不具备真实安全性，界面与代码注释中明确标注。

## 3. 信息架构

```
/login                    登录页（未登录唯一入口）
/                         首页大屏（主视图，含简化版世界地图）
/map                      全球交易地图页（独立页，空中连线）

/admin                    管理员控制台（用户 + Mock 数据 + 系统设置）  ← 仅 admin
```

页面关系：登录 → 大屏（默认落地页）；大屏顶部导航可切「态势总览 / 全球地图 / 交易明细 / 控制台」；大屏简化地图点击 → `/map`；地图连线点击 → 侧边详情 → 可跳 `/trades?tradeId=xxx`；告警条目点击 → 下钻到对应交易或节点。

## 5. 全球交易地图页（P0，独立页面）

### 5.1 底图与节点

- 暗色赛博主题世界地图，**本地 GeoJSON 世界国界数据**，不依赖在线瓦片 / 地图 token，保证离线可跑（`Q1` 确认后定渲染库）。
- 交易节点 = 城市 / 交易所，字段含 `id / name / nameEn / country / lon / lat / type / volume / status`。预置 20~30 个全球金融节点（上海、香港（中国香港）、新加坡、东京、伦敦、法兰克福、纽约、芝加哥、圣保罗、迪拜、悉尼等）。
- 节点视觉：发光圆点 + 脉冲环 + 体量大小映射成交额，状态用颜色区分（正常 / 高负载 / 异常）。

### 5.2 空中连线（核心需求）

- 每笔交易携带 `fromNodeId` 与 `toNodeId`，地图层按交易双方生成**弧形空中连线**（大圆路径近似或二次/三次贝塞尔，弧度与两地距离正相关）。
- 连线视觉：渐变霓虹线 + 沿线运动的粒子 / 拖尾，方向体现资金流向（卖方 → 买方），线宽映射金额，颜色映射资产类别或状态（青 / 品红 / 琥珀），异常交易用红色闪烁。
- 新交易产生时动态生成连线，动画结束后降低亮度保留为「历史航线」，可切换「仅显示实时 / 全部」。
- 高密度时提供节点聚合与线束合并，避免糊成一片。

### 5.3 地图页交互

## 6. 交易明细与管理台

- **交易明细**：虚拟滚动表格（千级数据不卡），列含时间、交易 ID、卖方节点、买方节点、资产、方向、金额、价格、状态、延迟、风险分；支持搜索、多条件筛选、排序、行点击抽屉、状态色标、一键复制交易 ID。
- **管理员控制台**：三个分区
  1. 用户列表（内置账号 + 演示用户）：启停、角色切换、一键切换当前身份；
  2. Mock 数据控制台：数据流启停、速率、随机种子重置、注入「大额交易 / 延迟尖刺 / 风控告警」、清空数据；
  3. 系统设置：动效强度（完整 / 降低）、配色主题（青紫 / 琥珀 / 冰蓝）、刷新频率、DEMO 水印开关。
- 所有管理操作仅影响前端内存状态，刷新后按种子恢复。

## 7. 视觉与动效规范（赛博 HUD）

### 7.1 色板

| 用途 | 色值 |
| --- | --- |
| 背景 / 面板 | `#05070D` / `#0A0F1C` / `#101A2E` |
| 主霓虹（青） | `#00F0FF` |
| 次霓虹（品红 / 紫） | `#FF2BD6` / `#7B5CFF` |
| 警示（琥珀 / 红） | `#FFB547` / `#FF4D6D` |
| 正常 / 成功 | `#39FF9E` |
| 文字 | 主 `#E6F5FF`，次 `#8AA3C0`，弱 `#4B6480` |
| 网格线 | `rgba(0,240,255,0.08)` |

**涨跌色遵循中国区规范：涨 = 红 `#FF4D6D`，跌 = 绿 `#39FF9E`**，仅用于价格涨跌数字与行情带；交易流向、状态色使用霓虹色系，避免红绿语义冲突。

### 7.2 形态与装饰

切角卡片（`clip-path` 八边切角）、1px 霓虹描边、四角准星、扫描线、背景网格、噪点、CRT 微光、HUD 编号标签、等宽数字字体（JetBrains Mono / Rajdhani 风格，本地字体栈兜底）、中文系统无衬线。标题支持低频 glitch 故障字效（可关闭）。

### 7.3 动效清单

数字滚动累加、KPI 卡片脉冲、飞线粒子流、节点呼吸环、告警闪烁、列表条目入场、图表渐进绘制、页面切换扫描过渡、悬停辉光反馈。提供「降低动效」开关（尊重 `prefers-reduced-motion`，低性能设备自动降级）。

### 7.4 适配

以 1920×1080 为设计基准，采用 `scale` 等比缩放 + 关键断点微调，覆盖 2560×1440、3840×2160、1366×768；单屏无滚动条；全屏模式隐藏浏览器边框外的辅助 UI。

## 8. 本地 Mock 数据设计

### 8.1 实体（TypeScript 类型预定）

```ts
type Role = 'admin' | 'viewer';

interface User {
  id: string; username: string; password: string;
  role: Role; displayName: string; enabled: boolean; lastLoginAt?: number;
}

interface TradeNode {
  id: string; name: string; nameEn: string; country: string;
  lon: number; lat: number; type: 'exchange' | 'clearing' | 'gateway';
  volume24h: number; status: 'normal' | 'busy' | 'alert';
}

interface Trade {
  id: string; ts: number;
  fromNodeId: string; toNodeId: string;
  asset: string; assetClass: 'fx' | 'equity' | 'crypto' | 'bond' | 'commodity';
  side: 'buy' | 'sell'; amount: number; price: number;
  status: 'filled' | 'pending' | 'failed' | 'flagged';
  latencyMs: number; riskScore: number;
}

interface Alert {
  id: string; ts: number; level: 'info' | 'warn' | 'critical';
  type: 'large_trade' | 'latency_spike' | 'risk_hit' | 'node_offline';
  tradeId?: string; nodeId?: string; message: string; handled: boolean;
}

interface MarketTick { asset: string; price: number; changePct: number; sparkline: number[]; }
```

### 8.2 生成策略

- **可复现**：seeded PRNG（如 `mulberry32` + 固定默认种子），同一 seed 得到相同历史，便于演示与截图对比。
- **历史数据**：启动预生成近 24h 时序（KPI、行情、约 800~1500 笔历史交易、告警）。
- **实时流**：定时器按默认 1.5s/笔生成新交易（速率可调），写入全局 store，驱动大屏、地图飞线、明细三处同步更新。
- **异常注入**：管理员可手动注入大额交易 / 延迟尖刺 / 风控命中，触发告警闪烁与红色连线。
- **接口抽象**：`src/mock/api.ts` 以 Promise + 模拟延迟暴露 `login / fetchTrades / fetchNodes / fetchTimeseries / fetchAlerts / updateUser`，UI 只依赖该层，未来替换真实 API 不改视图代码。
- **持久化范围**：仅会话与用户偏好存 `localStorage`；业务数据全部内存态，刷新重建。

### 10.1 关于「layopenjs」的澄清（关键）

目前公开 npm 生态中**没有**名为 `layopenjs` 的库；该名称可能是 `OpenLayers.js`、`AntV L7`、`Leaflet` 或某内部库的口误 / 混写。候选方案对比：

| 方案 | 包 | 空中弧线 | 离线无 token | 赛博表现力 | 备注 |
| --- | --- | --- | --- | --- | --- |
| **A（推荐）** | `@antv/l7` + `@antv/l7-maps` | 内置 `LineLayer` arc / arc3d + 动画 | ✅ 可用无底图 `Map` + 本地 GeoJSON 自绘国界 | ★★★★★ | 专为地理大数据可视化设计，飞线开箱即用，最贴合需求 |
| B | `ol`（OpenLayers） | 需自行插值大圆路径 + 自定义动画图层 | ✅ | ★★★☆☆ | 若 `layopenjs` 实指 OpenLayers.js，则选此项；GIS 交互强但飞线要手写 |
| C | `deck.gl` `ArcLayer` | 内置弧线 + 粒子，WebGL 性能最好 | ✅ 搭配本地 GeoJSON 底图 | ★★★★★ | 依赖较重，与 React 集成需额外封装 |
| D | `echarts` geo + `lines` | `curveness` 弧线 + `effectScatter` 拖尾 | ✅ 本地 `world.geo.json` | ★★★★☆ | 最省事、完全离线，但地图页深度交互弱于 A/C |

**默认建议**：按 A（AntV L7，无底图模式 + 本地世界 GeoJSON + ArcLayer 飞线）落地；若确认 `layopenjs` = OpenLayers.js 则改 B，若希望最轻依赖则改 D。首页简化地图始终用 SVG 自绘，不受此选择影响。

## 11. 验收标准（Definition of Done）

1. `npm install && npm run dev` 可离线启动，**运行时零外部网络请求**（无地图 token、无 CDN 字体）。
2. 1920×1080 下首页单屏完整展示、无滚动条、无元素溢出；2560×1440 与 1366×768 等比可用。
3. 两个内置账号可登录；`viewer` 访问 `/admin` 被拦截到 403，管理按钮不可见；切换身份后权限即时生效。
4. 首页、地图、明细三处数据同源：注入一笔新交易后，三处同步出现，地图生成对应空中弧线。
5. 地图页可按交易双方生成弧线，hover / 点击 / 筛选 / 回放 / 图层开关均可用；≥30 条并发弧线时帧率 ≥30fps。
6. 交互点清单 P0 项 100% 可用，P1 项按排期交付并明确标注。
7. 数据流 4× 倍速、连续运行 10 分钟无内存持续增长、无报错。
8. 所有数字带「模拟数据 / DEMO」标识；涨红跌绿符合中国区规范。
9. 「降低动效」开关与 `prefers-reduced-motion` 生效。
10. TypeScript 无类型错误，构建产物可通过 `npm run build`。

## 14. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 地图库名称歧义（Q1） | 返工 | 抽象 `MapAdapter` 隔离，选型只影响一个目录 |

| 未来接真实 API | 改动面大 | `mock/api.ts` 接口层隔离，视图不直接读数据文件 |
