# NEXUS DESIGN SYSTEM

**版本 / VERSION** `1.0` · **设计基准 / CANVAS** `1920 × 1080` · **数据状态 / DATA** `DEMO / 模拟数据`

NEXUS 是面向跨境交易运营的“赛博指挥中枢”，不是后台报表。视觉以深空黑为底，以青色 HUD 为默认信号，用品红标记风险与重点，用琥珀标记等待与异常关注，用红绿表达中国区价格涨跌。结构优先、层次优先、信息可读性优先；不使用圆角白卡、柔和 SaaS 渐变或居中营销标题。

## 2. 色彩 Token

```css
:root {
  --bg-0: #05070D;       /* 全屏底色 */
  --bg-1: #0A0F1C;       /* 面板底色 */
  --bg-2: #101A2E;       /* 浮层、输入框、表头 */
  --cyan: #00F0FF;       /* 主霓虹、常态数据、选中态 */
  --magenta: #FF2BD6;    /* 风险重点、加密资产、选中描边 */
  --violet: #7B5CFF;     /* 次级图表、辅助装饰 */
  --amber: #FFB547;      /* 等待、播放、提示与商品 */
  --red: #FF4D6D;        /* 异常、失败、价格或指标上涨 */
  --green: #39FF9E;      /* 正常、成功、价格或指标下跌 */
  --text: #E6F5FF;       /* 主文字 */
  --muted: #8AA3C0;      /* 次文字 */
  --dim: #4B6480;        /* 弱文字、单位、辅助标签 */
  --grid: rgba(0,240,255,.08);
}
```

### 语义分配

- **青色**：默认交互、实时数据、卖盘、链路与健康状态。
- **品红**：重点关注、风险命中、加密资产、已展开抽屉的焦点线。
- **紫色**：辅助序列与背景轨道，不承担唯一语义。
- **琥珀**：pending、播放中、商品资产、提示与阈值预警。
- **红色**：failed、异常线路、危险操作、价格/指标上涨。
- **绿色**：filled、在线、安全状态、价格/指标下跌。

> 中国区行情规范：涨 `#FF4D6D`，跌 `#39FF9E`。交易状态不能只依靠红绿区分；状态必须同时显示 `FILLED / PENDING / FAILED / FLAGGED` 文本和描边形状。

### 状态样式

| 状态 | 文字 / 边框 | 背景 |
| --- | --- | --- |
| FILLED | `var(--green)` | `rgba(57,255,158,.045)` |
| PENDING | `var(--amber)` | `rgba(255,181,71,.05)` |
| FAILED | `var(--red)` | `rgba(255,77,109,.05)` |
| FLAGGED | `var(--magenta)` | `rgba(255,43,214,.05)` |
| NORMAL | `var(--muted)` | transparent |

## 3. 字体与数字

```css
--sans: "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", system-ui, sans-serif;
--mono: ui-monospace, "JetBrains Mono", "SF Mono", Menlo, Consolas, monospace;
```

- 中文正文：系统无衬线，`13px / 1.6`。

## 4. 间距、尺寸与切角

- 基础间距单位：`4px`。
- 常用间距：`4 / 6 / 8 / 10 / 12 / 14 / 18 / 24px`。
- 页面外边距：`12–14px`；面板内部：`8–12px`。
- 顶栏：`64px`；首页行情带：`56px`；面板标题栏：`42–48px`。
- 表格行高：`54px`；紧凑控件高度：`27–34px`；主按钮高度：`33–46px`。
- 分隔线统一为 `1px`，透明度低于内容描边。

### 八边切角卡

```css
clip-path: polygon(
  0 10px,
  10px 0,
  calc(100% - 10px) 0,
  100% 10px,
  100% calc(100% - 10px),
  calc(100% - 10px) 100%,
  10px 100%,
  0 calc(100% - 10px)
);
```

- 大面板切角：`10px`。
- 按钮与输入框切角：`5–8px`。
- 禁止 `border-radius: 12px+`；圆形仅用于头像、状态点、雷达和轨道。
- 面板边框用 `inset` 阴影实现，切角内部不会出现直角描边残片。

## 5. 表面、描边与发光

```css
background: linear-gradient(135deg, rgba(16,26,46,.84), rgba(8,13,25,.94));
box-shadow:
  inset 0 0 0 1px rgba(0,240,255,.17),
  inset 0 1px 0 rgba(230,245,255,.04),
  0 8px 30px rgba(0,0,0,.24);
```

- 主描边：`rgba(0,240,255,.17–.25)`。
- 次级描边：`rgba(0,240,255,.08–.14)`。
- 选中描边：`rgba(0,240,255,.42–.55)` + 底部 `2px` 青色基线。
- 危险描边：`rgba(255,77,109,.24–.36)`。
- 主数字辉光：`0 0 14px rgba(0,240,255,.25)`；禁止给正文整段添加强辉光。

### 四角准星

面板内嵌 `5px` 的四角 L 形准星，长度 `14–23px`，颜色从青色过渡到品红，透明度 `.42–.48`。准星只做边界提示，不参与内容布局。

### 网格、扫描线与噪点

- 主网格：`48px` 间距，线色 `rgba(0,240,255,.08)`。
- 微网格：`12px` 间距，透明度 `.024`。
- 扫描线：`repeating-linear-gradient(0deg, rgba(255,255,255,.021) 0 1px, transparent 1px 4px)`。
- CRT 暗角：径向黑色遮罩，透明度不超过 `.48`。
- 噪点以 CSS 纹理或低透明静态叠层暗示即可，不依赖外部位图。

## 6. 组件语言

### HUD 面板

- 结构：`编号标签 + 中英标题 + 状态/操作区`。
- 编号格式：`D-01 / KPI`、`D-03 / GEO`、`M-01 / WORLD GRID`、`TXN / FOCUS`。
- 标题中文为主，英文大写副标题降低亮度。
- 面板头部高度固定，主体用 `flex: 1; min-height: 0` 填满。

### 按钮与切换

| 状态 | 视觉 |
| --- | --- |
| Default | 半透明深底、低亮青描边、`var(--muted)` 文字 |
| Hover | 背景提升至 `rgba(0,240,255,.06)`，描边 `.30`，出现轻微外辉光 |
| Active / Selected | 青色描边 `.48`，背景 `.08–.16`，底部 `2px` 青色实线 |
| Disabled | 描边降为 `rgba(75,100,128,.18)`，文字 `var(--dim)` |
| Danger | 红色描边与红色文字，背景不超过 `.06` |

- 开关轨道尺寸约 `34×17px`，开启时滑块右移并发青色小辉光。
- 滑杆轨道 `3–4px`，选中段使用青至品红的窄渐变，滑块为 `2–3px` 竖向亮线。
- 分段控件用 `1px` 分栏，不采用独立圆角胶囊。

### 表格

- 表头 `8px` 等宽字，弱色；数值列右对齐。
- 选中行：左侧 `2px` 品红基线 + `1px` 品红内描边 + 轴向微渐变。
- 虚拟滚动窗口只渲染可见行；底部状态栏显示 `RENDERED x / total`。
- 风险分使用文字 + 条形双重编码，不能只做颜色块。
- 延迟超过阈值时使用琥珀，失败/异常时使用红色。

### 详情抽屉

- 宽度 `500px`，与主内容间距 `12px`。
- 顶部标题、交易主金额、卖方→买方方向、结构化字段、风险、执行图表、审计信息、操作区按顺序排列。
- 卖方节点用红色、买方节点用青色；方向弧必须带箭头或粒子方向感。
- 操作按钮固定到底部，至少包含“主操作 / 风险处置 / 辅助操作”三级。

### 地图与飞线

- 大陆轮廓使用自绘 SVG path，海洋使用低亮网格，不依赖外部位图。
- 节点为 `halo + ring + core` 三层；重点节点带呼吸环。
- 资产线路：FX 青色、CRYPTO 品红、EQUITY 琥珀、ANOMALY 红色。
- 弧线由卖方发出、箭头指向买方；流动虚线或沿路径运动的粒子表示方向。
- 底图、网格、节点、标签、线路分别独立开关。

### 表单与认证

- 输入框高度 `42px`，前缀使用青色符号，聚焦态提高描边和内部微光。
- 验证码使用琥珀，叠加斜线纹理，仅作为本地静态演示。
- 登录页明确显示 `DEMO / 模拟数据`、访客身份和“不执行真实认证/下单/清算”的声明。
- 演示账号填充、显示密码、记住我会话、刷新验证码均为静态可见控件。

## 7. 动效 Token

| 动效 | 时长 | 曲线 | 用法 |
| --- | --- | --- | --- |
| Hover / 按钮反馈 | `160–200ms` | `ease-out` | 描边、辉光、底色 |
| 状态呼吸 | `1.8s` | `ease-in-out` | 在线数据点、告警角标 |
| 节点呼吸环 | `2.2s` | `ease-out` | 地图重点节点 |
| 飞线流动 | `2.8s` | `linear` | 常规线路 |
| 异常飞线 | `1.35s` | `linear` | 风险线路 |
| 扫描线 | `6–8s` | `linear` | CRT / 面板预览 |
| 行情滚动 | `28s` | `linear` | D-10 无限行情带 |

```css
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
```

- 动效仅作为方向、在线状态和层次暗示，不改变信息含义。
- 低性能环境关闭飞线粒子、扫描线和节点呼吸，保留静态描边与箭头。
- 预览图允许停止动画后截图，所有状态必须仍可辨识。

## 8. 交付约束

- 每个 HTML 单文件自包含：仅内联 CSS 与少量内联 SVG。
- 不引用外部 URL、字体、图片、JS 库或 CDN。
- 画布固定为 `1920×1080`，单屏无滚动条。
- 登录页不使用顶部导航；其余页面使用统一主导航与右上角身份徽章。
- 所有业务文案使用 `DEMO / 模拟数据` 环境标识，关键数据保持可信、可核对。
