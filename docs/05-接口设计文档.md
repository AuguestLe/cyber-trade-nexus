# 接口设计文档

| 项目 | 内容 |
| --- | --- |
| 文档版本 | v1.0（冻结契约） |
| 日期 | 2026-11-12 |
| 服务地址 | 开发 `http://127.0.0.1:8787`（Vite 以 `/api` 代理）；生产同源 |
| 内容类型 | 请求与响应均为 `application/json; charset=utf-8`；SSE 为 `text/event-stream` |
| 鉴权方式 | `Authorization: Bearer <token>`；SSE 使用 `?token=` 查询参数 |
| 时间口径 | 所有时间字段为毫秒级 Unix 时间戳（number），由服务端时钟产生 |

## 1. 通用约定

### 1.1 成功响应信封

```json
{
  "data": { },
  "serverTime": 1763000000000
}
```

- `data` 为各接口定义的载荷，可能为对象或分页对象。
- `serverTime` 必填，用于前端校准展示时钟。
- 所有接口响应头包含 `Cache-Control: no-store` 与 `X-Content-Type-Options: nosniff`。

### 1.2 错误响应信封

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "pageSize 必须在 1~200 之间",
    "details": { "field": "pageSize", "value": 500 },
    "requestId": "req_8f2a1c"
  },
  "serverTime": 1763000000000
}
```

### 1.3 分页约定

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `page` | number | 从 1 开始，缺省 1 |
| `pageSize` | number | 1~200，缺省 50 |
| `total` | number | 满足筛选条件的总条数 |
| `hasMore` | boolean | `page * pageSize < total` |

### 1.4 枚举

| 枚举 | 取值 |
| --- | --- |
| `role` | `admin` / `viewer` |
| `assetClass` | `fx` / `equity` / `crypto` / `bond` / `commodity` |
| `side` | `buy` / `sell` |
| `tradeStatus` | `filled` / `pending` / `failed` / `flagged` |
| `nodeStatus` | `normal` / `busy` / `alert` |
| `nodeType` | `exchange` / `clearing` / `gateway` |
| `alertLevel` | `info` / `warn` / `critical` |
| `alertType` | `large_trade` / `latency_spike` / `risk_hit` / `node_offline` |
| `window` | `1h` / `6h` / `24h` |
| `speed` | `0.5` / `1` / `2` / `4` |
| `injectType` | `large_trade` / `latency_spike` / `risk_hit` |
| `sortBy` | `ts` / `amount` / `price` / `latencyMs` / `riskScore` |
| `sortDir` | `asc` / `desc` |
| `theme` | 仅前端：`cyan` / `amber` / `ice` |

## 2. 认证接口

### 2.1 POST /api/auth/login

请求体：

```json
{ "username": "admin", "password": "admin123", "remember": true }
```

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| username | string | 是 | 2~32 字符，去首尾空格 |
| password | string | 是 | 6~64 字符 |
| remember | boolean | 否 | `true` 时会话 7 天，否则 8 小时 |

成功 `200`：

```json
{
  "data": {
    "token": "nx_9f3a...",
    "expiresAt": 1763604800000,
    "user": {
      "id": "u_admin", "username": "admin", "displayName": "系统管理员",
      "role": "admin", "enabled": true, "lastLoginAt": 1763000000000
    }
  },
  "serverTime": 1763000000000
}
```

失败：`401 INVALID_CREDENTIALS`（账号或密码错误，不区分提示）；`403 USER_DISABLED`；`400 VALIDATION_ERROR`。

说明：登录成功会更新该用户的 `lastLoginAt`，并广播一次 `status` 事件（在线会话数变化）。

### 2.2 GET /api/auth/session

请求头 `Authorization: Bearer <token>`。成功 `200`：

```json
{ "data": { "user": { "id": "u_admin", "username": "admin", "role": "admin" }, "expiresAt": 1763086400000 }, "serverTime": 1763000000000 }
```

失败：`401 UNAUTHORIZED`（无 token）/ `401 TOKEN_EXPIRED`（过期）/ `403 USER_DISABLED`（账号已停用）。

### 2.3 POST /api/auth/logout

请求头携带 token。成功 `200`：`{ "data": { "ok": true } }`。token 立即失效，重复登出返回 `401 UNAUTHORIZED`。

### 2.4 POST /api/auth/impersonate

管理员专用，用于演示身份切换。请求体 `{ "userId": "u_viewer" }`。

成功 `200`：返回与登录相同结构的新 token 与目标用户；旧 token 保持有效（便于切回）。

失败：`403 FORBIDDEN`（非 admin）；`404 NOT_FOUND`（用户不存在）；`403 USER_DISABLED`（目标停用）；`400 VALIDATION_ERROR`（userId 缺失）。

## 4. SSE 实时推送

### 4.1 连接

`GET /api/stream?token=<token>`，响应头：

```text
Content-Type: text/event-stream; charset=utf-8
Cache-Control: no-cache, no-transform
Connection: keep-alive
X-Accel-Buffering: no
```

- 服务端每 15s 发送 `heartbeat`；浏览器 `retry: 5000`。
- 无效 token 直接 `401` 并结束响应；服务端检测连接关闭后清理订阅。
- 客户端断线不自动补发历史；重连成功后调用 REST 接口重新拉取快照，再继续接收增量。

### 4.2 事件类型

| event | 触发 | data |
| --- | --- | --- |
| `hello` | 连接建立 | `{ meta: MetaDTO, status: StreamStatus }` |
| `trade` | 新交易 | `TradeDTO` |
| `alert` | 新告警 | `AlertDTO` |
| `kpi` | 每 2s | `{ window: "24h", items: KpiDTO[] }` |
| `market` | 每 5s | `{ items: MarketDTO[] }` |
| `status` | 数据流状态/会话数变化 | `{ paused, speed, intervalMs, clients }` |
| `heartbeat` | 每 15s | `{ ts: number }` |

示例：

```text
event: trade
id: 1243
data: {"id":"t_20261112_120001_1","ts":1763000000000,"fromNodeId":"n_sh","toNodeId":"n_ny","fromNodeName":"上海","toNodeName":"纽约","asset":"EUR/USD","assetClass":"fx","side":"sell","amount":12800000,"price":1.0842,"status":"filled","latencyMs":41,"riskScore":18}
```

### 4.3 StreamStatus

```ts
interface StreamStatus {
  paused: boolean;
  speed: number;      // 0.5 | 1 | 2 | 4
  intervalMs: number; // 1500 / speed
  clients: number;
  uptimeMs: number;
}
```

## 5. 管理接口（全部要求 admin）

### 5.1 GET /api/admin/users

`{ "data": { "items": UserDTO[] } }`，按 role、lastLoginAt 排序。

### 5.2 PATCH /api/admin/users/:id

请求体任选字段：

```json
{ "enabled": false, "role": "viewer" }
```

成功 `200`：`{ "data": { "user": UserDTO } }`。

规则：

1. 不能停用或降级当前唯一启用的管理员；违反返回 `400 VALIDATION_ERROR`，`details.reason = "LAST_ADMIN"`。
2. 不能修改自己的角色；违反返回 `400 VALIDATION_ERROR`，`details.reason = "SELF_ROLE"`。
3. 停用用户后，其所有会话立即失效。
4. 用户不存在 `404 NOT_FOUND`；非法 role/enabled `400 VALIDATION_ERROR`。

### 5.3 PATCH /api/admin/stream

请求体任选字段：`{ "paused": true }` / `{ "speed": 2 }`。

成功 `200`：`{ "data": { "stream": StreamStatus } }`。`speed` 只能取枚举值；暂停时仍接受 speed 修改，恢复后按新速率生成。

### 5.4 POST /api/admin/inject

请求体 `{ "type": "large_trade" }`，可选 `assetClass`、`nodeId` 用于定向注入。

成功 `200`：

```json
{ "data": { "created": { "trade": TradeDTO, "alert": AlertDTO } } }
```

- `large_trade`：生成 8,000,000~20,000,000 USD 的 `filled` 交易，触发 `large_trade` 告警。
- `latency_spike`：生成延迟 900~1600ms 的交易，触发 `latency_spike` 告警，状态 `pending`。
- `risk_hit`：生成风险分 85~99 的 `flagged` 交易，触发 `risk_hit` 告警。

### 5.5 POST /api/admin/reset

请求体可省略或 `{ "seed": 20261112 }`（seed 为 1~2147483646 整数）。

成功 `200`：`{ "data": { "meta": MetaDTO } }`。行为：清空交易与告警，按新种子重建 24h 历史，保留用户与会话，数据流状态复位为 `paused=false, speed=1`。

### 5.6 POST /api/admin/clear

清空全部交易与告警，不重建历史，返回 `{ "data": { "cleared": { "trades": number, "alerts": number } } }`。

### 5.7 PATCH /api/admin/alerts/:id

请求体 `{ "handled": true }`。成功 `200`：`{ "data": { "alert": AlertDTO } }`；不存在 `404 NOT_FOUND`。`handledAt` 由服务端写入。

### 5.8 GET /api/health

无需鉴权，用于存活探测：`{ "data": { "ok": true, "uptimeMs": 123456, "version": "1.0.0" } }`。

## 6. 错误码

| code | HTTP | 触发场景 |
| --- | --- | --- |
| `VALIDATION_ERROR` | 400 | 参数缺失、类型错误、枚举越界、分页越界、最后管理员保护 |
| `INVALID_CREDENTIALS` | 401 | 账号或密码不匹配 |
| `UNAUTHORIZED` | 401 | 缺少/失效 token（已登出） |
| `TOKEN_EXPIRED` | 401 | token 超时 |
| `FORBIDDEN` | 403 | viewer 访问管理接口 |
| `USER_DISABLED` | 403 | 账号被停用 |
| `NOT_FOUND` | 404 | 交易/告警/用户/路由不存在 |
| `METHOD_NOT_ALLOWED` | 405 | 方法不匹配 |
| `INTERNAL_ERROR` | 500 | 未捕获异常，日志含 requestId |

前端处理约定：

1. `401` 清除本地会话并跳转登录页，保留 `from` 路径。
2. `403` 非 `USER_DISABLED` 渲染 403 视图。
3. 其余错误显示可读 message，并保留上一次成功数据（不白屏）。
4. SSE 连续失败 3 次后顶部指示灯变红，但不打断浏览。

| `getArcs` | 聚合层按端点与资产分组 | 数仓预聚合表，按分钟窗口物化 |

| `getHealth` | 由延迟/状态推导 | 监控系统健康分接口 |
| `subscribe` | 进程内 EventEmitter → SSE | 消息总线（Kafka/Redis Stream）消费后转 SSE |
